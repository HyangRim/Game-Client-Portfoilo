### 담당 업무 및 경험. (누르면 세부 사항으로 이동합니다.)
 - 게임 엔진 제작(렌더링 파이프라인, 충돌, Imgui 연동, 셰이더 제작, 포스트 프로세싱)

 - 전장의 안개
 - 플레이어, 몬스터 부모 클래스 설계 및 구현, 비앙카 캐릭터 구현(스킬, 특성등)

 - 메인 게임 화면 UI 구성.
